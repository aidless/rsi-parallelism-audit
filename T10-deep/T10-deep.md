# T10-deep — N_eff–ρ 函数形式的闭合

**结论（先行）**：T10 §7 的中段 2.83× 差距是两个不同泛函共用 `N_eff` 符号的必然后果。在 ρ=0.5、N=16 上，`ratio = 插值/MC伪影 1.096 × 噪声基线口径 0.826 × 泛函形状差 3.125 = 2.829`。主导来源是「极值统计×幅度收缩」对「Kish 有理衰减」的形状差；把反解读数塞进 Kish 公式，对应的 Kish 相关只有 ρ_kish≈0.134，而非生成参数 0.5。

**边界**：仅闭合解析合成底物（best-of-N，ρ 为人为自变量）的函数形式问题；不外推真实系统，不把任何数字当成真实 `paired_gate` 的 ρ 或 N_eff 重测。

## 1. 两条曲线的闭式

设 `a_N = E[max(Z_1,…,Z_N)]`，`Z_i` iid N(0,1)。probabilists' Gauss–Hermite（256 节点，权重归一，积分带 x 因子）：

```
a_N = N ∫ x·φ(x)·Φ(x)^(N−1) dx = N Σ_i w_i x_i Φ(x_i)^(N−1)， a_16 = 1.7660
```

T10 底物：`q_i = √(ρk) + √(1−ρ)·z_i`，`ŝ_i = q_i + ε_i`，`ε~N(0,σ²)`。令 `W_i = √(1−ρ)z_i + ε_i ~ N(0,1−ρ+σ²)`，`Cov(√(1−ρ)z_i,W_i)=1−ρ`，按 W 取最大再取回增益：

```
Δ(ρ,N;σ) = (1−ρ)/√(1−ρ+σ²) · a_N
Δ₀(N)    = a_N/√(1+σ²)          （ρ=0 的 T10 反解基线）
Δ(ρ,N;0) = √(1−ρ)·a_N            （无噪极限）
```

MC 独立对表（A7，20k seeds）：(ρ,N)=(0,16),(0.5,16),(0.945,16),(0.5,4) 上解析 vs MC 最大相对差 0.0058。解析 vs 落盘 56 格最大绝对差 0.0828（ρ=0.25,N=2），在 400 seeds×56 格噪声包络内（A8 阈 0.10）。

- **Kish（方差膨胀口径，T5）**：`N_eff = N/(1+(N−1)ρ)`，ρ=0→N，ρ=1→1，严格递减（A1–A3）。
- **反解（增益等值口径，T10）**：`N_eff` 满足 `Δ₀(N_eff)=Δ(ρ,N;σ)`，反解 `A(m)=a_m`（log m 线性插值，钳位 [1,N]）：

```
N_eff_inv = A⁻¹( a_N · √(1+σ²)·(1−ρ)/√(1−ρ+σ²) )   （同噪，匹配 T10 落盘口径）
          → A⁻¹( a_N·√(1−ρ) )                       （σ→0 极限）
```

端点 ρ=0→N、ρ=1→1；401 点细网格单调不增且恒在 [1,N]（A4–A6）。

## 2. ρ=0.5 差距的三因子账（N=16，σ=0.5）

`ratio = N_eff_inv(存) / N_eff_kish = 5.3257 / 1.8824 = 2.8293`

| 因子 | 数值 | 含义 |
|---|---:|---|
| `factor_interp_mc` | 1.0962 | 存储反解 / 同噪闭式；N 轴分段线性插值与 400 seeds MC 残留，约 10% |
| `factor_noise_baseline` | 0.8259 | 同噪闭式 / 无噪闭式；T10 基线曲线本身带 σ=0.5 噪声，是口径定义差而非误差 |
| `factor_shape_functional` | 3.1251 | 无噪闭式 / Kish；纯泛函形状差：`A⁻¹(a_N√(1−ρ))` 对 `N/(1+15ρ)` |

乘积 1.0962×0.8259×3.1251 = 2.829269，与落盘 ratio 逐位闭合（A12）。准确表述：**主导来源是形状泛函不同（3.125×），噪声基线与插值伪影合起来把这一点调制到最终 2.829×**；不能把差值归咎于 Monte Carlo 精度。

## 3. 单调性与端点（T10 §6 的解析版证明）

- Kish 随 ρ 严格递减（201 点）；反解闭式随 ρ 单调不增（401 点）且恒在 [1,N]（A3/A6）。
- 落盘 56 格 N_eff 沿 ρ 无大于 0.05 的反向跳动；ρ=1 残留 1.0409 是反解上界截断/噪声，不是「ρ=1 还有 4% 独立度」。
- `ρ=0→N`、`ρ=1→1` 在两条闭式上都精确成立；中间不重合是泛函形状差，非端点 bug。

## 5. 遗留问题

1. **真实系统的 ρ 映射未闭合**：T5 的 ρ̄ 是 paired_gate 底物上候选 Δ 向量的平均 Pearson 相关；本文的 ρ 是 best-of-N 生成参数。二者是否可映射需单独标定，本文不给换算系数。
2. **σ 固定 0.5**：三因子账在当前 σ 下成立；σ 变化时基线噪与插值伪影会变；形状因子仅依赖 ρ、N，但仍受 A(m) 插值网格影响，未扫 σ 全域。
3. **Kish 口径的方差假设未在本底物验证**：Kish 是「相关样本均值方差膨胀」的有效样本量；本文只把它当给定闭式与反解比形状，不主张它是本 best-of-N 增益任务的正确尺。
4. **未做文献方向**：纯本地解析闭合，不开检索方向（工作纪律：最多 2 个方向，查不到即停）；「未核」= 外部文献一致性未核。

**证据等级**：A（本地可复跑、闭式+MC 双路径对表、12 断言、含反证、数字可从落盘 JSON 复算）；**适用范围**：仅解析合成底物的函数形式闭合，不外推真实系统。
