# T14 预注册设计：N_eff 在真实闸底物上的连续 ρ 检验

> 落盘时间：2026-11-20。执行前定，禁止事后挑数。科学问题来自 T10/T13 交叉面。

## 1. 问题与动机

T10 给出解析曲面：N=16 时 ρ=0→N_eff 16.00，ρ=0.5→5.33，ρ=0.945→1.42，ρ=1→1.04；净赚临界 ρ* 依赖外生基准 a。T13 在真实闸底物上实测四档提案器 ρ̄=0.858/0.910/0.520/0.538，得 rate16/rate4≈0.25/0.29，**ρ̄ 掉到 0.52 也没翻正**；gate_census 进一步显示过闸概率随 N 上升、拒因主项 NO_GAIN、Δ_priv 平坦。

两轨的张力在于：T10 说降低 ρ 能把 N_eff 拉回来从而救回 Δ；T13 说即使 ρ̄≈0.52，闸后 rate 仍降 4×。**本轨首次把两者焊在同一底物上**：用可控 ρ 提案器在 T13 的真实 ContextualTask + paired_gate 上扫连续 ρ，量 rho_param→实测 ρ̄→N_eff→Δ(N)→rate，判定 T10 的凸塌缩形态在真实闸底物上是否成立，并定位「闸前增益 vs 闸后采纳」的分界。

## 2. 仪器与底物（不改 rsi-agent 源码）

- 底物：完全复用 T13 的 `ContextualTask`(seed=1000+s, 128 episodes)、`paired_gate`、`estimate_noise_floor`、`BASELINE`，只换 propose。
- 新提案器 `controlled`：每 gen 先抽一个共享随机方向 shared∈R³，候选 i 的权重 w_i = anchor + step·(√ρ·shared + √(1−ρ)·ind_i)，ind_i 独立同分布 N(0,1)³，step=max(0.5·0.94^gen, 0.04)。ρ=1 时全候选同权重（Δ 向量全同→ρ̄=1）；ρ=0 时无共享方向。
- 已实测探针（seed=1, gen=0, n=16）单调性：rho_param 0/0.25/0.5/0.75/0.9/0.945/1.0 → ρ̄_measured 0.379/0.405/0.458/0.532/0.606/0.677/1.000（严格单调递增，端点非平凡）。**这是仪器有效性证据，不是结果**。
- ρ̄ 仪器：public per-episode Δ 向量两两 Pearson（与 T13 同）。注意 anchor=(1,0,0) 常量向量本身 pearson 分母为 0 返回 0（T13 self-test T5 已钉），故不得用纯 anchor 构造；本设计 w_i 非常量，规避该陷阱。
- N_eff 口径：Kish `n/(1+(n−1)ρ̄)`，与 T10 §7 的曲线反解 Δ₀⁻¹ 是**两个定义**，中段可差 2.83×；本轨只报 Kish 口径，不声称与 T10 反解值同尺度。

## 3. 预注册判据（执行前定死）

实验矩阵：rho_param ∈ {0, 0.25, 0.5, 0.75, 0.9, 0.945, 1.0}（7 档），N ∈ {1, 4, 16}，gens=12，seeds={1,2,3}。共 7×3×3=63 臂。主表按 (rho_param, N) 对 3 seeds 取均值。

**D1（T10 形态是否在真实闸底物成立）**：取 N=16 行，看 Δ_priv(ρ) 与 N_eff(ρ) 是否随 ρ 上升单调不增。判据：N_eff 由 Kish 定义天然单调（仪器性质，不作判决）；**判决量是 Δ_priv(ρ=0.0) 与 Δ_priv(ρ=1.0) 的差**——若 |Δ_priv(0.0)−Δ_priv(1.0)| < 0.05（即末端差小于 T13 实测 Δ_priv 量级 0.43–0.50 的 10%），判 `FLAT_GATE_DOMINANT`（T10 凸塌缩形态在真实闸上不成立，闸后增益被 gate 卡平）；否则判 `SHAPE_PRESERVED`。

**D2（rate 是否在任何 ρ 档翻正）**：对每个 rho_param，若 rate(16) ≥ rate(4) 则该档记 FLIP。判据：存在任一 ρ 档 FLIP → `RATE_FLIP_ANY`（直接翻转 T13 主轴）；否则 `RATE_ROBUST_ACROSS_RHO`（主轴从「四档提案器成立」升级为「连续 ρ 扫描成立」）。

**D3（N_eff 与过闸概率谁在主导）**：报告每档 pass_rate（过闸代数/总代数）与 promoted 数。判据：若 ρ 扫描下 pass_rate 随 N 上升而 Δ_priv 保持平坦 → 确认 T13 gate_census 的「过闸概率不是瓶颈、NO_GAIN 拒因主导」在连续 ρ 下仍成立；若 pass_rate 随 ρ 单调下降且与 Δ_priv 同向 → 判 `GATE_BOTTLENECK`（相关性通过降低过闸概率起作用）。

**D4（协调税 4× 的 ρ 依赖性）**：对每档 ρ 求使群体追平单体的预算比 B_cross（用 rate 反解：rate(N=4)·B4 = rate(N=16)·B16 ⇒ B16/B4 = rate4/rate16）。判据：报告该比值在 ρ 网格上的范围；若全档 ≥3× → `TAX_ROBUST`；若某档 <2× → `TAX_RHO_SENSITIVE`。

## 4. 证伪门（self-test 必须能红）

- S1 相同向量 ρ=1；S2 正交向量 ρ<0.5；S3 Kish N_eff 端点；S4 单向量返回 1；S5 假多样（全同非常量）ρ=1。
- S6 **反直觉陷阱守卫**：断言 rho_param 0→1 时实测 ρ̄ 严格单调不减且 ρ̄(0)<0.5、ρ̄(1)=1；若有人换回 `√ρ·anchor+√(1−ρ)·v` 那种构造（实测反单调），此门必须变红。
- S7 **常量向量守卫**：断言常量 Δ 向量 pearson 返回 0（而非 1），防止用退化构造假报 N_eff 塌缩。
