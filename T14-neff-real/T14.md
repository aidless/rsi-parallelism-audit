# T14：N_eff 在真实闸底物上的连续 ρ 检验

> 2026-11-20。预注册设计见 `PRE_REGISTRATION.md`（执行前定死）；脚本 `neff_real_substrate.py`；原始 63 臂数据 `real_substrate.json`。本地实验、未推送。

## 0. 一句话结论

**主轴加固但判据要降级解释**：连续 ρ 扫描（7 档 × N∈{1,4,16} × 3 seeds，63 臂）下 rate(16)/rate(4) 在**所有档都 <1**，协调税 3.48×–4.00×（D2=ROBUST、D4=TAX_ROBUST）；但预注册的 rho 旋钮在真实 outer loop 里被 **anchor 漂移吞掉**——实测 ρ̄(N=16) 只落在 0.84–1.00 窄带，N_eff 全程 1.00–1.19，**从未触发 T10 的 ρ=0→N_eff=16 曲面**。因此 D1 的字面 `SHAPE_PRESERVED` 不能读作「T10 凸塌缩在真实闸成立」，只能读作「在可达 ρ 窗口内 Δ_priv 随 ρ 上升下降 0.162」。T13 的 gate_census「过闸概率随 N 上升」在本提案器下不总成立（D3=MIXED）。

## 3. 仪器有效性：rho 旋钮被 anchor 漂移吞掉（本轨最重要的负面结果）

self-test 7/7 PASS，其中 S6 明确钉了构造单调性：在**固定 anchor 的 gen=0 探针**上，rho_param 0/0.25/0.5/0.75/0.9/0.945/1.0 → ρ̄ 0.379/0.405/0.458/0.532/0.606/0.677/1.000，严格单调；反例构造 `bad_propose`（√ρ·anchor+√(1−ρ)·v）实测反单调（0.529→0.000），门能红。

但**完整 arm 打开了 outer loop 的 anchor 更新**，逐代 trace（seed=1、N=16）显示：rho=0 时 ρ̄ 从 gen0 的 0.379 漂到 gen11 的 0.294，rho=0.945 时从 0.677 漂到 0.735——单代单调、跨代均值却被采纳后的 anchor 移动主导。最终 3 seeds 均值 ρ̄ 全被压进 0.84–1.00，**N_eff 全程 1.00–1.19**，T10 的 ρ=0.5→N_eff 5.33、ρ=0.945→1.42 曲面在真实闸底物上**没有被触发**。

后果：D1 字面触发的 `SHAPE_PRESERVED` 来自 ρ=1 档（所有候选权重全同→过闸率掉到 0.611→Δ_priv 掉到 0.337），不是来自「高相关压低 N_eff 再压低 Δ」。**不能拿 D1 去支持或反驳 T10 的凸塌缩机制**；在本底物上 T10 的 ρ 自变量不可操作化，这是一个明确的仪器边界。

## 4. 探索性诊断（post-hoc，不参与预注册判决）

为回答「若 rho 真能降下来会怎样」，跑了一个固定 anchor 的变体（废掉 outer loop 学习，只保留 gate 采纳判定）。ρ̄ 成功拉开到 0.390→1.000（N_eff 2.34→1.00），但 Δ_priv 只从 0.391 降到 0.299、rate 从 2.038 降到 1.559——**即使人为打开 ρ 跨度，rate(16) 仍远低于 rate(4)≈9/1k**，没有任何翻正迹象。这从另一个方向加固 D2：rate 下降不依赖 anchor 漂移，也不是单纯 ρ 的函数。该变体不是预注册实验，只作机理注记。

## 5. 对终局判断的影响

- **加固**：T13 的「跨提案器 robust」升级为「连续 ρ 扫描 robust」——7 档 rho_param 下 rate16/rate4 全 <1，协调税 3.48–4.00×，与 T7 的 ≈4×（k=8）同量级。
- **限定**：T10 的 ρ→N_eff 曲面仍是**解析底物结论**；本轨证明把它搬到真实闸底物时，ρ 不再是自变量（anchor 漂移吞掉旋钮），所以「独立度被相关性吃掉」这句机制话在真实闸上**缺少可操作化的 ρ 干预证据**。主轴里「并行买的是独立度」这半句仍只有 T7/T13 的提案器档位证据，没有连续 ρ 的因果证据。
- **新开放问题**：真实 outer loop 里 ρ 是 anchor 漂移的因变量，能否设计一种「冻结 anchor 但仍允许学习」的提案器，使 ρ 成为真正的外生旋钮？这是把 T10 曲面搬到真实闸的前置条件。
