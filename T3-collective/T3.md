## 0. 一句话结论

群体路线的正面证据最高只到 **B 级（0 篇严格 A）**；"等算力下群体优势消失"的反面证据有 **3 篇 A 级**（等思考 token 预算、516 配置预算匹配元分析、10× 成本仍输）。但反面研究全部测的是**答案型任务**（QA/推理/工作流），没有一篇测过 SwarmWorld 式**生态型端点**（组合韧性、验证发明数、无代理韧性）；正面与反面尚未在同一因变量上对撞——这是本轨最尖锐也最可执行的缺口。

## 2. SwarmWorld 解剖（本轨最重要一节）

以下数字全部来自 arXiv:2608.26081v1 HTML 全文【正文】（含图 4/13/14 及其图注），非摘要转述。

### 2.1 实验设计

- 两个配对研究：
  - **群体规模研究**：4 个机制消融条件（full culture / no communication / no explicit culture / independent search）× 800 ticks × N=50,100,200，每格 4 个配对 world seeds，8 个 held-out 扰动调度。
  - **长程研究**：N=100 跑 3,200 ticks，full culture / no explicit culture / endpoint-wise best-of-100 独立搜索包络线，冻结检查点 400/800/1,600/2,400/3,200。
- **世界种子是复制单元**（world seed = unit of replication）；作者明说 4 个配对种子下分析强调效应量与配对一致性，不做总体水平渐近推断【正文 §2.1】。
- 机制拆解：no communication 去掉消息/教学/交易但保留共享产物与程序继承；no explicit culture 再去掉跨代理程序 fork，只留物理 stigmergy；independent search 是 N 个隔离单代理世界。
- 提议–后果分离：LLM 出计划与主张，确定性模拟器独立裁定功能；评估时代理被移除，冻结状态克隆 8 份暴露于未见扰动，只留物理与已安装控制器运行。

### 2.2 四个指标怎么测

1. **Discovery-frontier AUC**：对"运行最优已测产物表现"随时间积分，奖励早出现且留在前沿的发现【正文 §2.2/图 4A】。
2. **Held-out resilience AUC**：代理移除后，冻结技术状态克隆 8 份配对未见扰动（污染/干旱/风暴，新中心/时序/顺序），平衡服务覆盖 Q_s(t) 在评估时间内积分、跨调度平均【正文图 3B】。
3. **Portfolio resilience**：最终产物集合的功能服务**广度+冗余度**【正文图 4C】。
4. **Validated inventions**：通过完整验证门的产物数——已测材料+完整设计+已安装代理自写程序+阈值表现+行为新颖性，五条全过才算"invention"【正文 §2.2/图 4D】。

### 2.3 对照的口径（判级关键）

- 每个社会都与 **endpoint-wise best-of-NN 包络线**比较：N 个隔离单代理、相同排程决策机会（same scheduled decision opportunities），且包络线的胜者可以随检查点/端点变化——作者称这是"deliberately strong control"【正文 §1/§2.2】。
- **决策机会数对齐**：两边总 LLM 决策调用数相同（N 代理 × 同一 macroturn 排程）。
- **token 未对齐**：全文未见两边 token 消耗记账；共享世界代理的 context 含共享记录/消息，单调用 token 口径未报告。→ 严格"等算力"只到决策数层面，缺 token 层。
- **缺第三种对照**：没有"把全部预算集中给一支单体"（budget-concentrated best-of-1）的对照——包络线是 N 支各 1/N 预算，不是 1 支拿 N 倍预算。

### 2.4 关键对照数字【正文图 4/13/14】

**800-tick 规模研究（vs 包络线的配对效应）**：
- Discovery AUC 随 N 非单调：N=50 时 full culture 与 no communication **输给**包络线；N=100 时三个共享世界条件全部超过；N=200 时 no explicit culture 最大配对增益 **+0.069**。
- Held-out resilience：几乎每个共享世界格都超过包络线。
- Validated inventions：no explicit culture 在 N=200 时平均配对增益 **+6 个发明**。
- Portfolio resilience：全程正配对效应。

**3,200-tick 终点（N=100，4 seeds，图 14）**：

| 端点 | full culture | no explicit culture | 独立搜索包络线 |
|------|------|------|------|
| Portfolio resilience | 0.2474 | 0.2365 | **0.1794** |
| Validated inventions | 5.75 | 7.00 | **2.75** |
| Held-out resilience | ≈同 no-EC | **0.0446** | 0.0356 |
| **最强单件**（best final artifact） | 0.2380 | — | **0.3488** |

- **最强单件反转**：单体包络线 0.3488 vs 群体 0.2380——独立搜索在"单件纪录"上仍赢。
- 文化交叉点因端点而异：best-artifact 约 tick 800 翻向 full culture；portfolio resilience 与累计产物约 tick 1,600 翻（277.5 vs 238.5 件）；inventions 永不翻（7.00 vs 5.75 反向）；held-out resilience 变号、3,200 处打平。→ 否定"沟通 amortize 后全面变好"的单一阈值叙事。

**机制与扩散【正文】**：
- ~95% 首次复用经**直接物理观察**（两条件同）；创作者→采纳者直接接触只在 25-tick 窗口弱超时序打乱零假设，50–400 tick 低于平价 → 传播主要靠世界而非对话。
- 复用率 99.3% vs 96.9%（非创作者复用比例）；首次复用中位时延 5 vs 8 ticks；采用广度 13.53 vs 7.49 人。
- 行为分化：长程 artifact-centered 表型 52.8% vs 31.0%（配对差 +21.8pp，95% CI 12.0–33.5，silhouette 0.472）；角色是动态状态（constructor/operator 0.008→0.535），非固定身份。
- 结构敲除是**图拓扑**测量：随机删半代理后 98.3%/95.2% 产物仍连通；删高度数节点降到 59.6%/73.9% → 集中性脆弱。作者自注：不证明活体世界中移除代理后的物理恢复。

### 2.5 SwarmWorld 证明了什么

1. 在**决策机会数对齐**、终点各异的有力对照下，共享物理世界在 portfolio resilience、held-out resilience、validated inventions 三个生态型端点上一致赢（效应量如上）。
2. 群体优势是**有界的（bounded swarm advantage）**：赢在"技术生态的组合"，输在"最强单件"——集体覆盖 ≠ 单件最优。
3. 协调的主要通道是**物理 stigmergy 而非对话**（95% 经观察；去掉显式文化常不降反升，如 inventions 7.00 vs 5.75）。
4. 涌现的分工可被 label-blind 聚类复现，且是动态状态非固定角色；架构可迁移到火山世界与蛋白质序列世界（后者是单种子描述性 pilot，作者明说不支持条件间推断比较）。

### 2.6 SwarmWorld 没证明什么

1. **token 级等算力**未记账（决策数对齐 ≠ token 对齐）。
2. **没有预算集中对照**：无法排除"把 N 倍预算喂给一支单体也能赢 portfolio"——2611.17610 的预算匹配分析恰好朝这个方向走（见 §3）。
3. 每格 **4 seeds**，作者自认推断受限（"claims should remain proportional"）；一个模型+一种 prompt 配置。
4. 任务域是**模拟器定义的material功能**，验证成本≈0；未测验证昂贵的域（湿实验）——而不等式（§4）显示结论对 v 高度敏感。
5. 蛋白质世界 pilot 单种子、无推断比较，不能当群体优势证据引用。
6. "生存/分工"不是独立测过的端点：分工是聚类描述，"生存"对应 held-out resilience（代理移除后的技术存活），没有代理 mortality/繁殖。

## 4. 准入条件：群体净赚不等式

记号：总预算 B（token 或墙钟）；N 支；每支协调开销 κ（被消息/检索/共识吃掉的预算）；单次验证成本 v（把一个候选推进"已验证"的成本）；单支搜索收益 S(c)=p(c)·q̄(c)，其中 p(c)=预算 c 下产出过验证门候选的概率，q̄(c)=过门候选平均质量；d=候选重复率（N 支独立采样的冗余）；M(c)=单体路线在同等总预算下的最大单件期望。

**净赚不等式（每总预算 B）**：

```
N_eff · S(c − κ) − v · N · E[n_cand(c−κ)]  >  M(B口径) − v · E[n_cand(B)]
其中  N_eff = N · (1 − d)，c = (B − κN)/N
```

左=群体路线净产出（有效支数 × 单支收益 − 总验证成本），右=单体路线净产出。判据：左 > 右 ⟺ 群体净赚。

三个必须进同一式的量及测法：
1. **单支验证成本 v**：每次候选评估的边际成本（模拟器 tick 数/湿实验美元/测试套件墙钟）。SwarmWorld 的 v≈0（确定性模拟器），这是它的群体优势**最可能不外推到湿实验域的原因**——v 越大，冗余采样越亏。
2. **协调成本 κ**：每支被协调占用的预算比例。SwarmWorld 实测【正文图 15B】：full culture 在 2,400–3,200 ticks 把 20.1 个百分点活动转给显式文化动作、movement −13.9pp——这就是 κ 的直接读数；且 κ 的失败形态有实测：N=50 时 full culture 在 discovery AUC 上输给包络线（协调挤占搜索）。
3. **单支搜索收益 S(c)**：从 trace 直接算 = 过验证门概率 × 过门平均质量。SwarmWorld 口径可用 validated inventions 数 × lifetime-peak score。
4. **冗余 d**：候选指纹（内容哈希/序列/配方）去重率。SwarmWorld 未测 d（遗留）；99.3% 非创作者复用率说明其冗余被继承机制回收成 r（继承增益）。
5. **M(B口径) 必须两种都算**：(a) best-of-N（N 支各 B/N，SwarmWorld 用的口径）；(b) budget-concentrated（1 支拿全 B，2611.17610 Category C 的口径）。SwarmWorld 只对照了 (a) 且仍输单件端点（0.3488 vs 0.2380）；对 (b) 完全无对照。

**把理论条件折叠进同一式**：2601.17311 的 s>β（组织增益指数须超叶代理缩放指数）对应不等式左边的放大因子——当单支本身缩放陡（β 大、预算喂一支更划算）时 M(B) 增长快于 N_eff·S(c)，群体亏；2601.17311 的共享误差相关 ρ 对应 N_eff 的折损（ρ→1 时 N_eff→1）；其消息保真 γ(m) 对应 κ 与继承增益 r 的折损。2611.17610 的正面条件（分区证据/外部验证/误差多样性）是 N_eff>1 与 r>0 的物理前提。

**SwarmWorld 实测分项代入（3,200 ticks，N=100，口径：图 14）**：
- 组合增益：+0.068（portfolio resilience 0.2365−0.1794）与发明数 +4.25（7.00−2.75，no-EC 口径）。
- 继承增益 r：首次复用时延 5 vs 8 ticks、采用广度 13.53 vs 7.49、谱系深度 9.75。

## 6. token 计价的协调税模型（用户 m01058「继续推进六个」，2026-11-19）

遗留 1「SwarmWorld 未报两边 token 消耗」是外部数据缺口，**本轮不造数**。改为把 T7 已实测的协调税从「评估次数」口径解析换算到 token 口径，参数显式外生、可复跑：

- 产物：`token_cost_model.py` + `outputs/token_cost.json`（读 T7 `collision.json` 的 40-seed agg，k=8）。
- token 模型：单次评估 `t_eval`（默认 1）；每 agent 固定上下文开销 `t_fixed`（系统 prompt+历史）。
  - 单体 token = `t_fixed + B_single·t_eval`；群体 token = `k·t_fixed + B_swarm·t_eval`
  - token 协调税倍数 = `(k·t_fixed + B)/(t_fixed + B)`：t_fixed=0 退化为 1（T7 评估次数口径）；t_fixed→∞ 时→k=8。

**表 1（token 协调税倍数，k=8）**：t_fixed=2/5/20/50 时，B=8 为 2.40/3.69/6.00/7.03×，B=128 为 1.11/1.26/1.95/2.97×。**预算越小、固定上下文越贵，群体税越重**（B=8 时逼近 8×上限）。

**表 2（同 token 预算下答案端点 A 胜者，W=群体/S=单体/`-`=群体付不起）**：
- t_fixed=0（评估次数口径）：T=8/16 群体赢、T=32/64 单体赢——**复现 T7 的交叉点 B≈16–32**。
- t_fixed≥2：交叉点左移（T=8 群体就付不起；T=16/32 单体赢）；t_fixed≥20 时全区间单体赢。
- 含义：真实系统里每个 agent 都有固定上下文开销，所以 T7「预算稀缺时群体也赢答案端点」的结论**在 token 口径下被削弱**——那个窗口只在 t_fixed≈0（无上下文开销的理想化）成立。

**表 3（生态端点 E 的净 token 效率 = E 增益 / token 溢价，B_swarm=128 vs B_single=32）**：ρ=0 时 0.125–0.202（t_fixed 50→0），ρ=0.5 时 0.071–0.114，ρ=1 时≈0。**即便扣掉 token 溢价，低相关区群体在生态端点仍有正净效率**——这是 T7 核心结论在 token 口径下依然成立的部分。

**三轨合并的口径结论**：T7（评估次数口径）说「预算稀缺时群体也赢答案端点」+「生态端点互补项不可复制」；本轮 token 换算把这两条分开判——
- **答案端点的稀缺预算优势是理想化产物**（依赖 t_fixed≈0），真实系统里有上下文税就不成立 → 削弱。
- **生态端点的互补增益在扣税后仍为正**（低相关区 net 0.13–0.20）→ 加固。

这与终局判断一致：真正值得买的从来不是答案端点，而是生态端点的互补项；而互补项的前提是候选低相关（ρ 小），又回到 T5/T10 的 N_eff 主轴。
